# Pre-V4 archive

These files are immutable historical snapshots from the earlier reconstruction. They preserve failed evidence, prior measurements, and the reasoning that led to V4, but they are not current implementation truth.

In particular, historical references to a 5×3 pool, `ExtrudeGeometry`, pre-V4 motion values, old private videos, or an earlier “Phase 0 complete” status must not be used as current acceptance evidence.

Current facts live in:

- `docs/v4/SOURCE_OF_TRUTH.md`
- `docs/v4/ARCHITECTURE.md`
- `docs/v4/KNOWN_GAPS.md`
- `config/calibration.v4.json`

Do not delete or rewrite this archive to make a later result look clean.
